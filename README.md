# What is Axion?
Axion is a kernel+OS written for the raspberry pi 4. It is designed to work together with a hardware package we are currently developing to create a fully-functional game console. 

AXION DOES NOT COME WITH ANY SECURITY GUARANTEES, NOR WILL IT EVER COME WITH SECURITY GUARANTEES IN THE FUTURE. However, we will still try to patch any security flaws we find. Please keep in mind that this is not our main field of work, so there will almost definitely be security flaws in our systems.

## Future Features
This project is still in very early development, so future features are not yet fully planned out. If you want to see what immediate software features are being added, then find posts tagged enhancements in the Issues tab.

## How to compile?
Compilation is currently not fully worked out. We are still in alpha, so we haven't finalized enough details to make compilation easy. You can still try to compile our kernel so far to see what it is like, but be warned that it has not yet been tested on hardware, and might CAUSE PERMAMENT, IRREVERSABLE DAMAGE to your system.

## I found an issue, now what?
Please raise an issue on the GitHub, and we will address it as soon as possible!
